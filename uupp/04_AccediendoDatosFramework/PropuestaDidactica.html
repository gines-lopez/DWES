    Propuesta didáctica UP 04: Accediendo a datos con framework¶

    Introducción¶

    La Unidad de Programación "Accediendo a datos con framework" tiene como objetivo dotar a los estudiantes de las competencias necesarias para desarrollar aplicaciones web dinámicas, organizadas y seguras que acceden y manipulan datos de manera persistente. A lo largo de esta unidad, se trabajará con tecnologías como PHP y el framework Laravel, permitiendo construir aplicaciones que integren operaciones de base de datos con estructuras modernas como el patrón MVC. Se hará especial énfasis en la conexión con sistemas de gestión de bases de datos mediante PDO, el uso de sentencias preparadas para prevenir inyecciones SQL, la gestión de sesiones y archivos. Además, se abordará el desarrollo orientado a objetos en PHP mediante un framework, facilitando la implementación de lógica de negocio clara y mantenible.

    Adicionalmente, se centrará en la calidad del software, capacitando al alumnado en la implementación de aplicaciones CRUD completas utilizando Laravel y Eloquent ORM. Se enseñará a estructurar proyectos según las convenciones del framework, gestionar rutas, controladores, vistas y modelos de manera coherente y segura, y a aplicar principios de diseño que fomenten la escalabilidad y el mantenimiento del código. A través de ejemplos prácticos y entornos virtualizados como Docker, los estudiantes desarrollarán competencias clave para el desarrollo profesional de aplicaciones web modernas y eficientes, integrando la lógica del servidor con una gestión de datos robusta y segura.

      1. Singleton

      4. DAO

      4. Lanza una excepción

      Respuesta correcta: c. Obtiene el ID del último registro insertado

      Respuesta correcta: d. routes/web.php
